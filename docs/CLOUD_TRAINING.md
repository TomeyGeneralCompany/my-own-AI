# Ancestor: owner-authorized eleven-book training without the laptop

The owner, the copyright holder's sole member and managing member, expressly
authorized public distribution of all eleven published books for Ancestor's
training. There is **no second repository**, cloud credential, personal access
token, release upload, or computer left powered on.

## Published sources in this repository

The \`published_library/\` directory contains 15 committed UTF-8 source-text
blobs representing all 11 owner-authored works, including every extracted
page of the 635-page Calvin commentary (stored in 5 ordered parts). Git object
hashes are pinned in \`ancestor/public_library.py\`; the importer rejects any
missing or unexpectedly changed part.

The original uploaded DOCX/PDF **binaries are not included in these commits**.
The committed files are FULL available text extractions of those originals,
rather than replacements for original layouts or figures. Thus Ancestor can
begin text-based learning without waiting for a binary-upload mechanism.
Embedded mathematical drawings, tables, charts and PDF images should still be
verified against the originals before claiming visual or diagram understanding.

Source names, ordered text units and actual extracted content are retained.
The Election treatise's original bracketed numbering is not redefined, and
the Latin treatise's two bracket-numbered sequences coexist in one source.
Unnumbered prose is indexed exactly like numbered prose. Each internal
learning-unit ID is not an added label in the owner's manuscript.

## Automatic training cycle

On a trusted \`main\` push affecting the published corpus / training workflow,
on a manual workflow dispatch, or every six hours:

1. A GitHub-hosted CPU checks out Ancestor and ALL eleven public texts.
2. The source importer verifies the SHA-1 Git blob identities; records
   exact extracted passages in the SQLite corpus with SHA-256 identity.
3. The setup generates a deterministic 320-base-vocabulary original BPE from
   the owner's published texts; neural learning uses ALL source passages, not
   just the tokenizer's vocabulary-training sample.
4. The governance manifest is generated from the owner's three explicitly
   stated imperatives — **honor God**, **love your kin**, **defeat your enemies** —
   and the already adopted verbatim six-governing-requirement intellectual
   constitution. These inputs are fixed between training runs. New doctrinal
   or mathematical axioms must be owner-authorized.
5. An independent, clearly labeled ordinary-English validation passage is
   generated by the code only to measure basic language continuation loss;
   it is NOT a replacement for owner-authored source material.
6. The workflow restores the newest valid complete checkpoint from its
   own GitHub Actions artifacts, including model, optimizer and RNG state.
   If any previous artifacts exist but all fail verification, the run stops.
7. Training from fresh original Ancestor weights (first run only) or the
   restored verified weights continues for a bounded hosted session.
8. Full model and recovery state are uploaded back as a new Actions artifact
   retained up to 90 days; successful six-hour runs refresh continuity.

GitHub-hosted Actions executes on **GitHub's infrastructure**, so the Zorin
laptop may remain completely shut down. CPU training is slower than GPU
training. A six-hour job limit applies; this job is intentionally shorter.

Training **does not prove** that the model has mastered the user's theology,
philosophy, mathematics or reasoning methods. The staged independent exams and
retention gates remain separate requirements for certification.

## Validation

- \`tests/test_published_library.py\` imports and hashes all eleven real
  published texts and exercises stable tokenizer and canonical-axiom bootstrap.
- \`tests/test_public_cloud_workflow.py\` checks that private-access and
  missing-release dependencies do not return.
- \`tests/test_cloud_training.py\` actually executes neural updates on synthetic
  passages and resumes complete checkpoints.

## Costs and checkpoint visibility

The public GitHub repository's Actions artifacts can be available to people
with repository read access, including learned checkpoint weights. That is
consistent with authorizing public training material but separate from book
copyright. Check current GitHub Actions billing and storage quotas before
assuming unlimited, cost-free hosted training.

Artifacts eventually expire; prolonged failure or disabled workflows beyond
the retention window requires an explicitly approved separate durable
storage plan. Do not silently start a fresh model when usable recovery state
was previously expected.
