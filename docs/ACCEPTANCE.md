# Foundation acceptance contract

Do not conflate CI passing with intellectual mastery.

## Automated engineering checks

- Byte-level reversibility with unfamiliar Unicode and control-token-looking text.
- Strict original architecture and future-token causality.
- Real gradient update using the fresh-weight model.
- Masked loss targeting derivations with injected prerequisites.
- Exact governance manifest and six owner requirements unchanged.
- No unapproved model/controller ability to overwrite axioms.
- Numbered paragraph import, source integrity and dependency lookup.
- Dictionary metadata is not accepted as headword.
- No stage completion without source coverage, independent competence and retention.
- Real checkpoint save and restore with optimizer state and neural continuation.
- Incompatible tokenizer, source manifest or governance blocks recovery.

## Owner corpus qualification (not pre-certified)

- Confirm approved original editions of every required treatise.
- Confirm every numbered paragraph, Terms./Consequence. block and equation.
- Confirm actual Webster 1913 edition, lexicographic traversal and full coverage.
- Approve exact axiom manifest and source version numbers.
- Approve real grading rubric, retention intervals, and pass thresholds.
- Train a small pilot then prove it uses changed non-governing premises.
- Verify skills beyond memorized source strings with held-out evaluations.
- Benchmark CPU runtime and memory on intended computer.
- Demonstrate interrupted full-stage controller-run recovery.
- Approve foundational certification before enabling specialist modes.

## Known boundaries

This pull request includes no original book contents, licensed book copies, trained
weights or validated Webster corpus. A software PR cannot invent owner's writings.
The CLI trainer can conduct next-token training but the complete autonomous
staged educational campaign is not yet integrated. These are blockers to claiming
an end-to-end trained and certified Ancestor; they must be tracked explicitly.
